# ELVIRA PLAZA RESIDENCE — Site vitrine

Site vitrine de **ELVIRA PLAZA RESIDENCE**, appartements & studios meublés à Yaoundé (Ngousso, Cameroun).

## Déploiement sur Vercel

1. Importez ce dépôt sur https://vercel.com/new
2. Framework Preset : **Other** (site statique)
3. Déployez — aucune configuration nécessaire

## Ajouter les photos

Placez les photos de la résidence dans le dossier images/ avec ces noms exacts :

| Fichier | Contenu |
|---|---|
| images/photo-1.jpg | Salon moderne (photo principale / hero) |
| images/photo-2.jpg | Chambre — lit à tête de lit dorée |
| images/photo-3.jpg | Séjour avec TV murale |
| images/photo-4.jpg | Salle à manger & cuisine |
| images/photo-5.jpg | Salon design bleu |

> Le site recadre automatiquement chaque photo (object-fit: cover). Tant que les photos ne sont pas ajoutées, des replis élégants s'affichent.
